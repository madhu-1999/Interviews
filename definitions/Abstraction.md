Hiding complex implementation details and showing only essential features.
+ [p] Reduces code complexity and isolates the impact of background changes
>[!example] 
>To drive a car, we don't need to understand how the engine works. 
>We only need to know about clutch, brake etc.
>Even if the engine is changed in the future, the steps we take to drive the car won't change i.e. changes in internal implementation does not impact the consumer of the abstraction.
